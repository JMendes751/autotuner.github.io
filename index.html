Robô de afinação automática de guitarra — ESP32

Este ficheiro contém o código C++ para o Arduino IDE, destinado a um protótipo de afinador automático de guitarra de seis cordas.

Nota de segurança: o código é uma base de protótipo e precisa de calibração antes de ser ligado a uma guitarra real. Confirma o sentido do motor, limita o binário e a tensão das cordas, e testa primeiro sem a guitarra. O algoritmo de deteção de pitch é inicial e pode precisar de melhorias para afinar com precisão.

Instala a biblioteca AccelStepper no Arduino IDE. O código usa a porta série a 115200 baud.
